## 环境硬约束（照做，别试）

- **不要在命令里用管道**（`| Select-Object` 等）：沙箱禁命名管道，`node.exe` 会报 `Access is denied`。
- **Chrome / harness 必须提权**：给**那一条命令**加 `sandbox_permissions: danger-full-access` + 一句理由；
  判据是**看到 `shot: …` 与 `==== 完成 ====`** 才算跑完（否则 `CDP ok` 之后就没了）。跑前先 `Stop-Process chrome` + 删 `tmp_chrome_profile`。
- 若报 `no sandbox backend is usable on this host`（纯文档命令也会中招）：**同一条命令原样提权重试**，命令本身不改。
- 本机**无外网**：Tailwind / KaTeX CDN 一律加载失败；浏览器实测走 `file://` + harness 生成的离线页面。
- 中文文件**只能用 write / Edit 或 node 的 `fs.writeFileSync(...,'utf8')`**；不要用 PowerShell 改中文文件。
- **本机 `pwsh` 实为 Windows PowerShell 5.1**：`.ps1` 若没有 UTF-8 BOM 会按 ANSI(GBK) 解码，
  中文字符串中段会把紧随其后的引号吃掉 → `ParserError`（窗17 实测）。**工具脚本一律写 `.js`（node 读 UTF-8，无此坑）**。

## 干活的轨道（`§3.9` 双轨）

- **做模块**：P0 → P1 侦查（子代理核考情 + 读 1 个同族模块）→ P2 写代码（先把数据模型与不变量写进注释）→
  P3 Node 冒烟（先打中间量、再写断言）→ P4 浏览器实测（**提权**）→ P5 接线五件套（模块文件 / `app.js` 转 ready /
  `exam-history` / `index.html` 的 `v+1` / README）→ P6 收尾。
- **纯文档 / 数据对账**：P2–P3 可省，但 **P1 的对账脚本要当回归测试留着**；收尾只跑"全站遍历 + 零异常"那一栏。
- **theory 文案体检**：按书分批；写盘前先跑结构检查（三问 / 考情块 / 裸尖括号 / 裸反引号）。
- 可照抄的脚本清单：`§3.5-18` 的"哪类活抄哪个脚本"表 + `docs/tmp-index.md`。

## 验收（按轨道选一种，判据见 `§3.9` P6）

- **A 做模块**：① 接线五件套齐；② Node 冒烟全过（含默认输入 / 量纲 / 类型串味）；③ 浏览器实测新模块 + 收尾全站遍历零报错。
- **B 纯文档**：① `tmp_readme_audit.js check` 四模式 0 不一致；② `doc_check.py` 全绿；③ 全站遍历零报错 + CDP 零异常。
- **C theory 体检**：① 三问 + 四块（考情块放最后 ≤2 行）；② 理论区 harness 报 `结构不合格=0 考情块超2行=0` + 截图目视；
  ③ 同 B；④ 动过公式再跑 `tmp_t10_harness.js`；⑤ 改了模块 js 就要 `v+1`。

## 三条"这窗最贵"的纪律（本项目实测的学费）

- **数字一律现算**：文档里的考频 / 计数 / 年数一律用 `RC408.examHistory` 或对账脚本现算，**不照抄旧文案**
  （窗6/12/13/14 都因为照抄而错，四模式对账一处都查不到）。
- **判据自己会失效**：任何"必须为 0"的指标报红，先问"它在这批数据上还成立吗"；改过被检查文本的格式，
  回头验一次它还会不会红（`§3.8-17`，**已复发多次**，最近一次是窗17 的"判据只认一种文档结构"）。
- **红了一片先归三栏**：真 bug / 测试脚本 bug / 环境噪声；《红色绝大多数出在自己写的断言上，先怀疑测试》。
