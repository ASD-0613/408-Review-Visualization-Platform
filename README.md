# 考研 408 复习可视化平台

将 408（数据结构、计算机组成原理、操作系统、计算机网络）的抽象知识点转化为**可操作的交互式可视化**：
用户单步执行 / 拖动滑块 / 修改输入，界面即时给出节点变色、连线高亮、数据流动、状态切换等反馈。
不是播放视频，而是"每一步都亲手推"。

**模块选题依据真题数据驱动**：平台内置知识点全部对照 `408真题及解析/`（2009–2026 共 18 年统考真题）
的考点统计与 `考纲/25考研408大纲.pdf` 选取与排序，各模块理论区顶部附有「📊 真题考情」标注，
完整统计见本文末尾 [真题考情分析](#二-真题考情分析20092026)。

---

## 一、快速开始

**直接双击 `index.html` 即可在浏览器打开**。全部脚本为普通 `<script>` 引入，无需本地服务器、无需构建；
唯一的外部依赖是 Tailwind CSS（CDN 方式），**首次打开需要联网**（离线时页面顶部会出现提示条）。

- 推荐浏览器：Chrome / Edge / Firefox 最新版
- 快捷键（单步型模块）：`→` 单步 · `←` 回退 · `空格` 播放/暂停 · `R` 重置
- 展示区右上角缩放工具：`－ / 100% / ＋`（50%~150%），点击中间数字复原
