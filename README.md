# 考研 408 复习可视化平台

将 408（数据结构、计算机组成原理、操作系统、计算机网络）的抽象知识点转化为**可操作的交互式可视化**：
用户单步执行 / 拖动滑块 / 修改输入，界面即时给出节点变色、连线高亮、数据流动、状态切换等反馈。
不是播放视频，而是"每一步都亲手推"。

**模块选题依据真题数据驱动**：平台内置知识点全部对照 `408真题及解析/`（2009–2026 共 18 年统考真题）
的考点统计与 `考纲/25考研408大纲.pdf` 选取与排序，各模块理论区顶部附有「📊 真题考情」标注，
完整统计见本文末尾 [真题考情分析](#二-真题考情分析20092026)。

## 一、快速开始

**直接双击 `index.html` 即可在浏览器打开**。全部脚本为普通 `<script>` 引入，无需本地服务器、无需构建；
唯一的外部依赖是 Tailwind CSS（CDN 方式），**首次打开需要联网**（离线时页面顶部会出现提示条）。

- 推荐浏览器：Chrome / Edge / Firefox 最新版
- **真题总览（题目 · 模块索引）**：顶部最左边那个「🧭 真题总览」页签。它把 2009–2026 共 18 年的真题
  按 **年份 × 题号** 铺成一览表（左边年份、上边题号，**最新年份在最上**），**点某个题号方块，就跳到演示这道题考点的那个模块**；
  同一道题有多个模块都登记时，会弹一个小浮层让你挑一个（不替你做主）。
  - 方块颜色：**选择题统一蓝色**；**大题那 7 列的颜色 = 这道题的科目**（🟦数据结构 / 🟨计组 / 🟩操作系统 / 🟥计网）；
  - 虚线描边的方块 = 这道题还没有对应模块；灰色方块 = 该年卷面没有这个题号；
  - 方块底部有一条粗线 = 这道题被 2 个以上模块登记（点它会让你选）；
  - 左侧目录会变成「年份快速定位」，点年份直接跳到那一年那一行；
  - 想打印成一张大表：浏览器打印（选 A3 横向、勾上「背景图形」）即可。
- 快捷键（单步型模块）：`→` 单步 · `←` 回退 · `空格` 播放/暂停 · `R` 重置
- 快捷键（标注模式）：`A` 一键开启/关闭理论区的标注模式（与点「✏️ 标注」按钮等效）
- 展示区右上角缩放工具：`－ / 100% / ＋`（50%~150%），点击中间数字复原
- **理论区可以用红字做标记**：点理论卡右上角的「✏️ 标注」进入标注模式（也可直接按 `A` 键一键开关），
  **按住鼠标左键拖选文字、松开就变红**
  （只把字变红，字重字号不变）；**再选一次同一段红字即恢复原色**；「清空本卡」可一次清掉本知识点的全部标记
  （两击确认）。标记存在**本机浏览器里**，刷新页面、切到别的知识点再切回来都还在；顶部的「历年考察分布条」
  与公式不参与标注。

### 复习提示

1. **性价比最高的三块**是 OS 的 PV 大题、计组的 Cache 与补码（每年几乎必考，平台里都有可交互模块，先去玩这三块）；
2. **计网大题**几乎固定为"网络综合分析"（子网划分 + 设备选型 + 协议交互），先用 `net-subnet` 把手算练熟；
3. **数据结构大题**是算法设计题（链表 / 数组 / 图），平台更适合练"过程与性质辨析"（排序每趟、树的旋转、堆的调整）；
4. 反复出现的**送分题型**：复杂度分析（9/18 年第 1 题）、栈出入序列（9/18 年）、物理层计算（11/18 年）——
   都适合用即时计算器反复刷。

## 三、常见问题

**Q：双击打开后样式全没了 / 排版错乱？**
A：平台用 Tailwind 的 Play CDN，**首次打开需要联网**；离线时页面顶部会出现提示条。若要完全离线，
需把 Tailwind 换成静态 CSS（属开发改动）。

**Q：侧栏那些徽标是什么意思？**
A：🔥 大热考点（考频 ≥8/18 年或大题 ≥2 道）· 📖 纯理论速记卡（已完工，直接展示考点）·
📕 考纲外（真题考过但现行考纲已删）· 「敬请期待」= 仍在建设中的条目（按真题考频排优先级）。

**Q：考情数据是哪来的、准吗？**
A：基于 `408真题及解析/` 里 2009–2026 共 18 年真题 + 解析逐题统计（该目录不入库，克隆后自行放入同名目录）。
每个模块理论区顶部的「📊 真题考情」块与该模块的考情表一致。

**Q：能离线 / 能手机看吗？**
A：能离线运行（首次联机加载样式后浏览器会缓存）；手机端可横向滚动目录，但交互演示建议在桌面浏览器上做。

**Q：理论区的红字标记存在哪、会丢吗？**
A：存在**你这台电脑的浏览器本地**（不联网、不上传），换浏览器或清空浏览器数据就不在了；
红字只影响显示、不会改动考点内容，点「清空本卡」可随时清掉。
